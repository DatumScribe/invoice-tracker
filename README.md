# Simple invoice and payment tracker for Excel

A one-page product site for the [Excel invoice tracker](https://scribebot2.gumroad.com/l/xykdf?utm_source=datumscribe&utm_medium=github_pages&utm_campaign=e03_invoice_tracker). It describes the workbook's verified features, limitations, price, and AI-assisted creation disclosure. The page uses no analytics scripts, fonts, or third-party assets.

The preview is the existing product image. The workbook itself is delivered by Gumroad and is not stored in this repository.
